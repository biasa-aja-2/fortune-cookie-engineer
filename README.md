The funniest one-line fortune cookie message for a software engineer, 120 characters or fewer.

> Your pull request will be approved by someone who read only the title and felt brave.

## Why this line

A real fortune cookie message: short, declarative, second person, with its
twist coming from the engineer's world of code review. The setup promises
a blessing every engineer wants — a pull request approval — and the
punchline undercuts it: the approver read only the title and approved out
of bravery, not understanding. A fresh angle (the brave rubber-stamp
reviewer, not the usual deploy-on-Friday or bug-count jokes), it lands on
first read, with the funniest word — "brave" — sitting at the end.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python stdlib, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
self-check gate (1–120 characters, single line, not whitespace-only) and a
byte-exact read-back verification.
